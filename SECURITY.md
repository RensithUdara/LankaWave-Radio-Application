# 🔐 Security Policy

## 🛡️ Supported Version

Security fixes apply to the latest version deployed from the default branch.

## 🚨 Reporting a Vulnerability

Please do not publish exploitable security details in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when available. Include:

- A clear description of the issue
- Reproduction steps
- Affected browser or environment
- Expected security impact
- Any suggested mitigation

You should receive an initial acknowledgement within seven days. Please allow reasonable time for investigation and remediation before public disclosure.

## 🔎 Scope

Relevant reports include cross-site scripting, unsafe URL handling, credential exposure, privacy regressions, and deployment misconfiguration. Availability problems in third-party radio streams are not LankaWave security vulnerabilities.
